09  /  Challenges faced  [required]

Four limits. Fail safe, not silent.

  • 0
    formats, uneven evidence

    PDF, DOCX, XLSX and TXT share a path; embedded Office images still require review.

  • 0
    extractors, not an oracle

    Each model reads independently. Disagreement, missing values, or an API error remain unresolved.

  • 0
    fields need conservative normalisation

    Units and counts are validated in Python. Port aliases and fuzzy matching are deferred, not guessed.

  • 0
    MB maximum expanded Office archive

    This is a synchronous MVP. Large or untrusted mail needs job isolation and resource quotas.

  • 0
    persistent approvals or Gmail OAuth in this build

    The current queue reads the local participant bundle. Review actions are session-only: a known boundary, not a hidden claim.

10  /  Future roadmap  [required]
