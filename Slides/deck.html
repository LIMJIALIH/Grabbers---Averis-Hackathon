09  ·  Challenges faced

DocuVerify

Challenges faced

THE PROBLEMWHAT HAPPENSTHE FIX
64spellings for 7 fields
Labels differ per document, some bilingual — 装货港, 毛重(KGS).
Normalise, then match ordered patterns. NOTIFY before CONSIGNEE.
2bookings, one subject line
The subject reads like a comparison thread. The body asks about something else.
Classify on the body alone. The subject is decoration.
1symptom, two causes
A failed read and a real discrepancy both end as “these don't match”.
Unread values escalate. Only a value read on both sides can mismatch.
0ways to check one model
Self-reported confidence says nothing about whether the value is right.
Gate at 0.70. Below it, a second model, then a person.

All four surfaced by running the pipeline over the real documents. None was visible from the brief.
